# PC Tycoon Enhanced

[日本語](README.md) | **English**

An offline Android company-management game with a Japanese interface. Research technology, design hardware, assemble PCs, manage a company, and develop fictional AI and LLMs. It does not train real AI models.

## Installation

Download the `pc-tycoon-debug-apk` artifact from a successful `verify` run in [Actions](https://github.com/pengin0503/PC-Tycoon-Enhanced/actions), then install it on Android. Physical-device acceptance is separate from automated tests and is not guaranteed complete.

## Saves and time

Game time advances through player actions or while the app is in the foreground. Saves are stored on the device. Debug signing can differ between build environments, so export and back up your save as JSON before replacing an installation.
