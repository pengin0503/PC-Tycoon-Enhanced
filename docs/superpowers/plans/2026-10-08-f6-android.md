# F6 Android Packaging Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans; Native, no subagents, author review.
**Goal:** Package the shared engine/save schema into a buildable offline Android APK with a real JSON export path.
**Architecture:** Capacitor8 consumes root dist with no remote server URL. SaveDocument writes bounded UTF8 through ACTION_CREATE_DOCUMENT; browser uses Blob downloads. File input uses Capacitor's picker. APK build and physical-device acceptance are separate.
**Tech Stack:** Capacitor8.5.3, Gradle8.14.3/AGP8.13, Java21, SDK36.
**Spec:** docs/superpowers/specs/2026-10-08-pc-tycoon-enhanced-foundation-design.md
