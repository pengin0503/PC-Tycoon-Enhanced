# F6 Offline PWA Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Native execution; no subagents, author review and automatic continuation authorized.
**Goal:** Production shell supports a new company, deterministic ticks, local saves and JSON transfer offline.
**Architecture:** Vite emits a content-versioned service worker from the actual production assets. Precache includes HTML/scripts/CSS/Japanese fonts/manifest/original icons. Only same-origin static GETs are cached; snapshots remain in IndexedDB. Atomic installation retains the prior shell on failure; activation waits for closed game windows.
**Tech Stack:** Existing React/Vite, Service Worker/Cache API, production Playwright server.
**Spec:** docs/superpowers/specs/2026-10-08-pc-tycoon-enhanced-foundation-design.md
