# Browser and Android distribution
Run npm ci and npm run build; publish the entire dist/ directory to static HTTPS hosting. For a subdirectory use npm run build -- --base=/your-path/. Development uses npm run dev; production enables offline caching.
First online visit downloads about6MiB including Japanese fonts and reports オフラインでプレイ可能 when ready. A new game, simulation, saves and JSON then work offline. Home-screen installation gives standalone display. Saves belong to the browser/profile/origin; export JSON before changing origin or clearing storage. Storage failures are shown.
Updates install into a content-versioned shell cache. A failed asset download discards the incomplete cache. Close all game windows and reopen to activate; no mid-game takeover. Activation removes owned shell caches only and never IndexedDB. Only static built content is cached; no save upload/server dependency.
Verify with npm run build && npm run test:pwa: real disconnected Chromium new company/tick/save/reload/font/JSON, failed update, successful update preserving save. npm run test:e2e covers development/mobile320–390px/desktop/keyboard/hidden timing.

Android requires Node22+, Java21 and Android SDK36; requirements follow official Capacitor v8 docs and pinned8.5.3 template. Run npm run android:build then npm run android:verify. Source wrapper and web game share save version1; all dist files must match APK assets byte-for-byte. CI uploads pc-tycoon-debug-apk after compilation/asset/signature verification. Debug signing is for installation tests; release signing/store publication are later work.
Install app-debug.apk on a test device (Android7/API24+ with current WebView), initially with network disabled. Start a company, advance ticks, save, close/reopen. Test touch/keyboard/insets and each screen. JSON書き出し uses Android's document picker; choose local storage. Browser export→APK import and APK export→browser import must give equal continuation; malformed JSON must preserve the old game. Native app storage and browser IndexedDB are separate; transfer via JSON rather than assuming shared origins.
Actual device launch, picker, persistence after restart and cross-device JSON transfer are unverified until tested with hardware. No main merge or production deployment has been performed.

Runtime and Japanese-font upstream license/copyright notices are bundled under dist/licenses/THIRD_PARTY.txt and included in the APK's same byte-exact asset check.
